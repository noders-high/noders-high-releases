# Noders High — CLI Releases

This repository hosts **public download artefacts** for the Noders High
CLI agent (`noders-agent`). Source code lives in a separate private
repository.

## Install

The official one-liner is on https://noders-high.org/download — copy the
appropriate command for your OS.

Direct downloads:

- **macOS Apple Silicon**: [`noders-agent-darwin-arm64`](https://github.com/noders-high/noders-high-releases/releases/latest/download/noders-agent-darwin-arm64)
- **macOS Intel**: [`noders-agent-darwin-x64`](https://github.com/noders-high/noders-high-releases/releases/latest/download/noders-agent-darwin-x64)
- **Linux x64**: [`noders-agent-linux-x64`](https://github.com/noders-high/noders-high-releases/releases/latest/download/noders-agent-linux-x64)
- **Linux arm64**: [`noders-agent-linux-arm64`](https://github.com/noders-high/noders-high-releases/releases/latest/download/noders-agent-linux-arm64)
- **Windows x64**: [`noders-agent-windows-x64.exe`](https://github.com/noders-high/noders-high-releases/releases/latest/download/noders-agent-windows-x64.exe)

Each release ships an [`SHA256SUMS.txt`](https://github.com/noders-high/noders-high-releases/releases/latest/download/SHA256SUMS.txt)
so you can verify the binary you downloaded matches the one we built.
